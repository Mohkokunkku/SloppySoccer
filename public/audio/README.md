# Game voice assets

Original callout text recorded locally through Windows System.Speech, using installed Microsoft desktop voices. No voice cloning or remote speech service is required for playback.

- pass-me.wav: "Pass me!" — Microsoft David Desktop, rate 2
- here.wav: "Over here!" — Microsoft Zira Desktop, rate 2
- goal.wav: "Goal! Come on!" — Microsoft Hazel Desktop, rate 2

Kick thumps and the small goal fanfare are generated in the browser with Web Audio. Sound is opt-in and can be muted. Pass calls are rate-limited and require an open supporting teammate.
