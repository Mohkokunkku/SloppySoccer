# National toy-pop victory music

Two **approved** original120BPM,4/4,16-bar instrumental recordings are generated by `scripts/generate-national-victory.py` and saved at `public/audio-v5/`. Both are32-second stereo24kHz/16-bit PCM WAVs. The standalone sound board at `.local-server/music-board/sound-board.html` embeds MP3 versions and works offline; it does not require a server and its controls do not change game settings. Controls include individual playback/seek, automatic one-track-at-a-time switching, shared volume, loop and Stop all.

Melodies are recovered from actual source MIDI rather than approximate placeholder motifs: Spain's97-note Marcha Real line (JoseanE's freely released historical-melody arrangement, cross-checked against the Flutetunes melody) and Argentina's68-note chorus (official embassy MIDI, VOZ track5, beats232–296). `public/audio-v5/melodies.json` records the quantized pitch/start/duration data; `CREDITS.md` gives exact sources and reference SHA256 hashes. Only the melody is retained; all accompaniment, timbres and recording are new. Modern official orchestration/master recordings are not copied.

Initial generic placeholder motifs failed explicit reference-melody and stereo asset tests and were replaced, not presented as valid anthem covers. The final asset tests pass, and independent browser playback verified both actual embedded MP3s, no autoplay, one-track-at-a-time behavior, volume, loop, stop/reset, mobile layout and zero page errors. Browser evidence/screenshots: `.local-server/music-board/verification.json`, `desktop.png`, `mobile.png`. Both native audio elements report exactly32seconds and readyState4 with no decode error. Waveform metrics are not a subjective listening approval.
